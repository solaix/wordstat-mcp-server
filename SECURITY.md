# Security Policy

## Supported versions

Security fixes are provided for the latest published version. The project is currently in
pre-release development and has not yet been published to npm.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/solaix/wordstat-mcp-server/security/advisories/new

Include reproduction steps, the affected version, the expected impact, and any suggested
mitigation. You should receive an initial response within seven days.

For ordinary bugs that do not have security impact, use the public issue tracker.
